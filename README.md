# Threshold Selection to Split Attritional from Large Claims

This repository contains the R code developed and used as part of the Master's thesis **“Threshold Selection to Split Attritional from Large Claims”**.

## Description

The code provided in this repository was used throughout the implementation, evaluation, and analysis of the threshold selection methods considered in the thesis.

It includes the procedures required to apply and compare the different threshold selection approaches used to distinguish attritional claims from large claims.

## Files

* `TESE.R` — Main R script containing the implementation of the threshold selection methods and the analyses presented in the thesis.

## Software

The analyses were performed using **R**. The required R packages are specified within the script.
